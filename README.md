# Polaris

A fork of The Graph Protocol's Horizon-era contracts deployed on Arbitrum One.
USDC payments. wstETH staking collateral. No native token. No inflation.
Fully open-source, permissionless, and decentralised.

```
contracts/    — Solidity contracts (fork of graphprotocol/contracts @ Horizon mainnet)
spec/         — Technical specification and feasibility study
node/         — graph-node operator configuration for Polaris testnet
```

See [spec/technical-spec.md](spec/technical-spec.md) for the full design.
